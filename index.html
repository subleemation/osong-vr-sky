이렇게 보세요

  1. 폰 화면 밝기를 올리고 VR로 보기를 눌러요.
  2. 폰을 가로로 돌려 헤드셋에 넣어요.
  3. 앉아서 고개를 천천히 돌려요. 진행자가 시작하면 장면이 저절로 이어져요.
  4. 별이 둘로 보이면 고개를 숙여 아래를 보세요. 설정판의 버튼을 1초쯤 바라보면 눌려요.
  5. 자유롭게 둘러보는 시간에는 설정판 오른쪽에서 일주운동, 별자리 그림 같은 것을 직접 켜고 끌 수 있어요. 화면으로 볼 때는 위쪽 보기 버튼을 눌러요.

사용 설명서

VR로 보기

  1. 폰 화면이 꺼지지 않게 밝기를 올리고, VR로 보기를 눌러요.
  2. 폰을 가로로 돌려 헤드셋에 넣어요.
  3. 앉아서 고개를 천천히 돌리며 하늘을 둘러봐요.
  4. 가운데 동그라미로 별자리를 바라보면 그림과 설명이 나와요.
  5. 별이 둘로 보이거나 방향이 어긋나면 고개를 숙여 아래를 보세요. 설정판에서 두 화면 간격, 렌즈 보정, 방향을 맞출 수 있고, 버튼은 1초쯤 바라보면 눌려요.
  6. 메뉴로 돌아오려면 설정판의 메뉴로 버튼을 바라보거나, 화면을 두 번 톡톡 눌러요.

화면으로 보기

  1. 손가락으로 끌어서 하늘을 둘러보고, 두 손가락으로 확대해요.
  2. 가운데 동그라미에 별자리나 별을 두면 설명이 나와요.

하늘 고르기

  1. 언제 하늘을 볼까요?에서 날짜와 장소를 고르고, 저녁 6시부터 다음 날 아침 6시까지 시각을 움직여 봐요.
  2. 시간 흐르기를 빠르게 하면 별이 북극성 둘레를 도는 모습이 보여요.
  3. 무엇을 보여줄까요?에서 별자리 그림·선·이름, 별 이름, 은하수, 동서남북, 별의 궤적을 켜고 끌 수 있어요.

어지러우면 바로 벗고 쉬어요. 어린이는 3분 정도만 보는 게 좋아요.
